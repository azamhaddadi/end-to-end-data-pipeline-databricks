# End-to-End Data Pipeline (Databricks)

## 📌 Project Overview

This project simulates a real-world data engineering pipeline using NYC Taxi data.

## ⚙️ Tech Stack

* Python
* PySpark
* Databricks
* Azure (optional)

## 🧱 Pipeline Stages

1. Data Ingestion
2. Data Cleaning
3. Data Transformation
4. Aggregation & Analytics
5. Output Storage

## 📊 Goal

To build a scalable data pipeline that processes raw taxi data into business-ready insights.
